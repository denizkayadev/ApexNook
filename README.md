# ApexNook

ApexNook is a Data-Driven Real-Time Analytics Platform Engine that leverages Auto-Scaling Architecture for high-performance processing.

ApexNook is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ApexNook.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ApexNook, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
